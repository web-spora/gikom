# Аудит маркетинга ГИКОМ

Папка содержит сводный и канальные аудиты, исходные выгрузки и дашборд.

## Структура

```
audit/
├── index.html                 — дашборд (точка входа)
├── README.md                  — этот файл
├── dashboard/                 — UI дашборда
│   ├── css/styles.css
│   ├── js/charts.js           — SVG-графики (bars, hbars, donut, grouped, line)
│   ├── js/app.js              — логика и рендер дашборда
│   ├── js/data.js             — данные (единственный источник правды)
│   ├── img/logo.png           — логотип ГИКОМ
│   └── channels/              — детальные аудиты по каналам (7 страниц)
└── data/                      — исходные выгрузки и аудиты
    ├── summary/               — сводный аудит (audit-summary.xlsx)
    ├── metrika/               — Яндекс Метрика
    │   ├── audit-metrika.xlsx
    │   └── exports/           — 6 исходных выгрузок
    ├── direct/                — Яндекс Директ
    │   ├── audit-direct.xlsx
    │   ├── exports/           — мастер-отчёты, запросы, площадки и др.
    │   └── archive/           — дубликаты (kampanii == устройства)
    ├── business/              — Яндекс Бизнес
    ├── 2gis/                  — 2ГИС
    ├── youtube/               — YouTube (xlsx, zip, csv)
    ├── rutube/                — RuTube + скриншоты
    └── dzen/                  — Дзен
```

## Периоды данных

- Метрика: 01.11.2025–31.10.2026
- Директ: 01.11.2025–07.11.2026 (на 7 дней длиннее)
- Яндекс Бизнес: 01.01.2026–06.11.2026
- YouTube: 01.01.2026–06.11.2026
- 2ГИС: ноябрь 2025 – ноябрь 2026
- RuTube: 07.11.2025–06.11.2026
- Дзен: «всё время» (~11.12.2024–06.11.2026)

Абсолютные показатели каналов между собой не сравнивать — периоды различаются.

## Главное ограничение

Это аудит каналов и веб-аналитики, не аудит продаж: данные Битрикс24, выручка и маржа не предоставлены.
