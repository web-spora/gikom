# gikom

Репозиторий проектов ГИКОМ.

## Проекты

- [Лендинг GIKOM (TakeYours Picking)](landing/) — интерактивный одностраничный лендинг для B2B-клиентов: визуальная система управления складской комплектацией, интерактивная демонстрация, калькулятор экономического эффекта, форма заявки.
- [Контент для мессенджеров и соцсетей](content/) — каталог примеров постов и статей в адаптивной веб-версии для согласования с руководством (публикация через GitHub Pages).

## Структура репозитория

```
gikom_web/
├── landing/    — лендинг (HTML5 + CSS3 + JavaScript)
├── content/    — материалы для мессенджеров и соцсетей
└── README.md
```
