# Контент для мессенджеров и соцсетей (GIKOM)

Папка для публикации примеров постов и статей в адаптивной веб-версии.
Каждый материал размещается в отдельной подпапке с понятным именем по заголовку.

## Структура

```
content/
├── index.html              — каталог материалов
├── css/content.css         — общие адаптивные стили
├── _template/              — шаблон для нового материала
└── <название-материала>/   — папка конкретного поста/статьи
    └── index.html
```

## Правила
- Имена папок — транслитерация/безопасные символы, без пробелов (используйте `-`).
- Каждый материал — отдельный `index.html` со ссылкой на общий `../css/content.css`.
- Адаптивность: mobile-first, корректное отображение на экранах от 320px.
- Публикация через GitHub Pages: ссылки относительные.
- Демонстрационные данные явно помечаются как демонстрационные.
