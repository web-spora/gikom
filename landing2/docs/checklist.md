# Контрольный список перед публикацией

## Содержание
- [ ] Все тексты соответствуют `GIKOM_automatic.pdf` или актуальным ТКП.
- [ ] Цифры в блоке `specs` файла `data/data.js` сверены с ТКП №2753-3 и №2753 от 02.09.2025.
- [ ] Нет экономических обещаний без расчёта и нет неподтверждённых сроков.
- [ ] В тексте нет упоминаний сторонних брендов и заказчиков, если не согласовано.
- [ ] Трианон указан как «склад Трианон», без утверждений о его оснащении сверх чертежа.

## Фирменный стиль
- [ ] Цвета: `#97242B`, `#707070`, белый фон, текст `#222222`.
- [ ] Шрифт Bahnschrift отображается (локально установлен или файл `bahnschrift.ttf` загружен, статус 200).
- [ ] Логотип не искажён (`height`, пропорции), размещён на белом фоне.
- [ ] Декор (диагонали, скосы) не конкурирует с текстом.

## Контакты
- [ ] Все 6 офисов: Москва, Краснодар, Казань, Ростов-на-Дону, Воронеж, Ставрополь.
- [ ] У каждого офиса: адрес, телефоны, эл. почта, режим работы.
- [ ] Общий бесплатный телефон, общая почта, сайт.
- [ ] Все 5 каналов: Telegram, Дзен, RuTube, YouTube, Instagram (+ сайт). Ссылки открываются.
- [ ] QR-код ведёт на `https://gikom.ru/`.

## Техника
- [ ] Страница открывается двойным кликом по `index.html` и через GitHub Pages без ошибок в консоли.
- [ ] Ссылки навигации подсвечивают активный раздел при прокрутке.
- [ ] Мобильное меню открывается и закрывается.
- [ ] Галерея открывается в полноэкранном режиме, закрывается Esc и кликом по фону.
- [ ] Блоки появляются при прокрутке; при `prefers-reduced-motion` анимации отключены.
- [ ] Адаптив проверен на ширинах 375, 768, 1280 px.
- [ ] Изображения сжаты до разумного размера; `alt` заполнен у всех.
- [ ] Lighthouse: доступность и производительность не ниже 90 (желательно).
