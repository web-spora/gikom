# ГИКОМ — лендинг «Автоматизированные складские системы СКАС»

Одностраничный лендинг по материалам `GIKOM_automatic.pdf`: задача склада, принцип работы штабелера,
сравнение СКАС-50 и СКАС-1200, управление, планировка, безопасность, преимущества, этапы внедрения,
фото объектов и контакты.

## Запуск

Откройте `index.html` двойным кликом. Сервер не нужен: данные подключаются обычным скриптом.

Публичная версия: GitHub Pages (адрес — в описании репозитория).

## Как править содержимое

1. Тексты, пункты, фото и контакты — в `data/data.js`, блок `content`.
2. Технические цифры — в `data/data.js`, блок `specs`. Менять только по актуальным ТКП.
3. Порядок и состав секций — функция `render` в `js/render.js`.
4. Новое фото: положите файл в `assets/images/gallery/` и укажите путь в `data.js`.
   Большие фото желательно сжимать до 1600–2000 px по длинной стороне.
5. Цвета и шрифт — только в `css/tokens.css`.

Файл `data.js` написан как обычный JavaScript-объект. После правки достаточно обновить страницу в браузере.
Если страница пустая, откройте консоль: ошибка почти всегда в запятой или кавычке в `data.js`.

## Фирменные требования

- Основной цвет `#97242B`, дополнительный `#707070`, фон `#FFFFFF`, текст `#222222`.
- Шрифт Bahnschrift. Не подменяется другим шрифтом без согласования.
- Логотип не искажается и не перекрашивается.
- Контакты: все офисы, телефоны, почта, режим работы, все каналы. QR-код дополняет текст.
- Декор (диагонали логотипа, скосы) не должен мешать чтению.

## Известные ограничения

- **Шрифт.** Файл `bahnschrift.ttf` не хранится в репозитории: его лицензия на веб-публикацию не подтверждена.
  Если Bahnschrift установлен в системе, он используется автоматически. Иначе применяется запасной шрифт.
  Для публикации с фирменным шрифтом нужен файл с лицензией на веб-использование.
- **Логотип.** Есть только PNG. Для сайта желательна SVG-версия.
- **Цифры и кейсы.** Технические значения взяты из ТКП. Экономический эффект и срок окупаемости
  не публикуются без расчёта по данным склада.
- **Фото.** Пять фото (`DSC02241`, `DSC02270`, `DSC02289`, `DSC02299`, `DSC02311`) содержат
  логотипы сторонних производителей оборудования. Перед публикацией проверьте их использование.
- **Проверка на устройствах.** Адаптив проверен по коду; рекомендуется просмотр на телефоне.
